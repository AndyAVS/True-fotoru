## Кастомизация форума foto.ru
Скрипт для Tampermonkey. 

### Зачем?
Скрываем посты некоторых пользователей. Устанавливаем стили форума, пригодные для просмотра фото. Убираем артефакты "игнор-листа" - когда заигнорили нас. Декоративно, но возвращаем некоторые кнопки интерфейса форума.

### Как установить
* Стянуть к себе  **True-Fotoru.user.js**  из последнего [release](https://github.com/AndyAVS/true-fotoru/releases/) Tampermonkey, если установлен, подхватит его.
